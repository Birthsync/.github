Ссылка на лендинг: <https://birthsync-landing.vercel.app>

Целью данного практического задания было создать лендинг-сайт-визитку для проекта Birthsync, который бы служил публичной витриной продукта и отражал его ключевые особенности. Основными требованиями являлись соответствие фирменному брендбуку, адаптивность под мобильные устройства и готовность к деплою на платформу Vercel.

### **Процесс разработки лендинга**

Целью данного этапа стало проектирование и реализация сайта в современном технологическом стеке. В основу легла архитектура **Next.js (App Router)** с применением **Tailwind CSS** для стилизации и адаптивной вёрстки. Такой выбор позволил достичь высокой скорости разработки, гибкости и простоты деплоя на Vercel.

При создании дизайна особое внимание уделялось фирменному стилю. Внедрены брендовые шрифты *Advent Pro* и *Source Code Pro*, а также цветовая палитра из брендбука: фиолетовый `#d791ff`, синий `#3A5BC4`, зелёный `#CDF4AF`, чёрный и белый. Это обеспечило консистентность визуальной идентичности проекта и подчеркнуло его узнаваемость.

Структура сайта была выстроена по классической схеме лендинга: **Hero-экран с ключевым слоганом и CTA**, блок «Функции», демонстрация интерфейса («Как это выглядит»), секция тарифов, представление команды и финальный call-to-action с формой обратной связи. Для мобильных пользователей реализован слайдер в разделе со скриншотами, чтобы контент оставался читаемым и удобным.

Дополнительно был реализован модальный компонент с **QR-кодом**, который открывается при нажатии кнопки «Попробовать» или после отправки формы. Это обеспечивает прямую интеграцию с ботом Birthsync и делает переход пользователя максимально удобным.

### **Процесс тестирования и публикации**

После завершения вёрстки сайт был загружен в GitHub-репозиторий и подключён к Vercel. Благодаря этому каждая новая ветка и Pull Request автоматически порождают **Preview Deployment**, что позволяет тестировать изменения в реальном окружении перед их публикацией. Финальная версия задеплоена в продакшн и доступна по доменному имени, привязанному к проекту.

### **Итоговые требования к доработкам**

В ходе работы над сайтом были выявлены и реализованы следующие доработки:

|                             Вопрос / Проблема                             | Решение                                                                                              |
| :-----------------------------------------------------------------------: | ---------------------------------------------------------------------------------------------------- |
|               **Мобильная версия скриншотов слишком сжата**               | Внедрён свайпер-слайдер (Swiper.js) для отображения по одному экрану с возможностью пролистывания.   |
|                **Градиенты выглядели резкими и обрывались**               | Градиенты переписаны с использованием промежуточного `via`-цвета для более плавного перехода.        |
|         **Кнопка «Попробовать» не имела прямой связи с продуктом**        | Добавлен модаль с QR-кодом для перехода к боту.                                                      |
|        **Несоответствие фирменному стилю (шрифты, цвета, палитра)**       | Внедрены Advent Pro и Source Code Pro, обновлена палитра в Tailwind под брендовые цвета.             |
| **Автоматизация тестирования изменений при pull-requests** (CI/CD аспект) | Использованы возможности Vercel: каждый Pull Request разворачивается в отдельный Preview Deployment. |
