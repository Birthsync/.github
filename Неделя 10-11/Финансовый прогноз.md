
Начнём с определения ключевых предположений и переменных. Чтобы построить финансовую модель на 2–3 года, нужно задать следующие исходные параметры:

| **Параметр**          | **Обозначение**                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Пользовательская база | **Начальное количество пользователей:**<br>возьмём $50.000$ как основу точки безубыточности;<br>**Темп роста пользователей в месяц:**<br>пусть будет примерно $5-15\%$ клиентской базы;<br><br>**В качестве конверсии бесплатных пользователей в платных возьмём примерно $3-7\%$ от общих значений активной базы.**                                                                                                                                                                    |
| Модели монетизации    | **1) Подписка:**<br>стоимость: $99\textbf{руб./мес.}$ или $999\textbf{руб./год}$;<br>предположим, что $70\%$ выбирают годовую подписку (более выгодный план), а $30\%$ месячную подписку;<br>**2) Партнёрские программы:**<br>прогнозируемый доход с одного пользователя, учитывая переходы по реферальным ссылкам (например, $10–15$ руб. на пользователя в месяц);<br>**3) Рекламный заработок:**<br>доход на одного пользователя бесплатной версии (например, $5–10$ руб. за месяц); |
Мы не учитываем расходы в данной модели, т.к. это финансовый прогноз доходов; также рекламный заработок является примерным значением.
### **Формулы:**

|              Категория              | Формула                                     |                                                                                   Обозначения                                                                                   |
| :---------------------------------: | :------------------------------------------ | :-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|            **Подписка**             | $N_p=N_o \times C_p$                        |                                      Платные пользователи ($N_p$), где $N_o\ -$ общее число пользователей, а $C_p\ -$ конверсия в платные.                                      |
|                                     | $R_m=(N_p\times\%_m)\times P_m$             |                              Доход от месячных подписок ($R_m$), где $\%_m\ -$ доля месячных подписчиков, а $P_m\ -$ стоимость месячной подписки.                               |
|                                     | $R_y=(N_p\times \%_y)\times \frac{P_y}{12}$ | Доход от годовых подписок ($R_y$), где мы делим результат на $12$ для ежемесячного дохода, а процентиль месячных подписок $\%_y=(1-\%_m)$, $P_y\ -$ стоимость годовой подписки. |
| **Партнёрские программы и реклама** | $R_p=N_o\times \textbf{ARPU}_p$             |                    Доход с партнёрских программ, где $N_o\ -$ общее число пользователей, а $\textbf{ARPU}_p\ -$ есть заработок с пользователя по партнёрке.                     |
|                                     | $R_a=(N_o-N_p)\times \textbf{ARPU}_a$       |                   Доход с рекламы, где $(N_o-N_p)\ -$ общее число бесплатных пользователей, а $\textbf{ARPU}_a\ -$ есть заработок с пользователя за рекламу.                    |
